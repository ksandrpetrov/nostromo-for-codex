# Документация Nostromo Codex

Здесь разделены поддерживаемые инструкции и датированные снимки состояния.
Для текущей разработки используйте документы из первого списка; старые
аудиты не доказывают состояние более новой ревизии.

## Поддерживаемые документы

- [`../README.md`](../README.md) — назначение, требования и быстрый старт.
- [`../ARCHITECTURE.md`](../ARCHITECTURE.md) — владельцы состояния, контракты
  и критические инварианты.
- [`testing.md`](testing.md) — безопасные автоматические и ручные проверки.
- [`hardware-acceptance.md`](hardware-acceptance.md) — физическая и live
  приёмка.
- [`design/ux-research.md`](design/ux-research.md) — исследование и принципы
  интерфейса.
- [`../CONTRIBUTING.md`](../CONTRIBUTING.md) — правила изменений и PR.
- [`../SECURITY.md`](../SECURITY.md) — сообщение об уязвимостях.

## Архив

- [`audits/2026-07-26/`](audits/2026-07-26/) — release, architecture и
  user-acceptance audits конкретного состояния исходников.

Архивные значения test count, hashes, окружения и статусы нельзя переносить
в текущий README без повторного прогона на актуальной ревизии.
