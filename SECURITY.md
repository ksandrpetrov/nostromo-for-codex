# Security policy

## Поддерживаемая версия

Security fixes принимаются для текущего состояния ветки `main`. Публичных
поддерживаемых бинарных релизов пока нет.

## Сообщение об уязвимости

Не публикуйте exploit, bridge token, пользовательскую конфигурацию или другие
чувствительные детали в обычном GitHub issue.

1. Используйте **Security → Report a vulnerability** в этом репозитории.
2. Если private vulnerability reporting недоступен, выберите issue template
   **Security contact request**. Укажите только общую область и попросите
   владельца открыть приватный канал.

В сообщении укажите затронутую ревизию, macOS/ChatGPT build, ожидаемое и
фактическое поведение, минимальные шаги воспроизведения и оценку возможного
воздействия.

Особенно важны сообщения о:

- выполнении действия в ChatGPT без явного пользовательского ввода;
- потере или повреждении конфигурации;
- залипании PTT либо pressed action;
- обходе HID isolation, compatibility gate или bridge authentication;
- изменении файлов установленного `ChatGPT.app`;
- небезопасном удалении runtime directory или owner marker.

Подтверждение получения и сроки исправления зависят от воспроизводимости и
риска. До публикации исправления детали уязвимости должны оставаться
приватными.
